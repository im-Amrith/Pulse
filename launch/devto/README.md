# dev.to and Hashnode versions

Each file has dev.to front matter (`title`, `published: false`, `description`, 4 `tags`, `canonical_url`, `cover_image`).

- **dev.to:** New post → switch to the Markdown editor → paste the whole file, front matter included → preview → set `published: true` (or click Publish).
- **Hashnode:** New article → paste everything below the front matter → in the article settings, set **Canonical URL** (under "Are you republishing?") to the `canonical_url` value, add the cover image and 4 tags.

The `canonical_url` tells search engines the original is on pulse-bot.dev, so cross-posting doesn't count as duplicate content. Publish the pulse-bot.dev version first.

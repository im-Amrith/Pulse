# Shorts, Reels and TikTok

Hooks, captions and hashtags for vertical video, plus the YouTube uploads.

**Footage you can use**
- `promo/final/pulse-promo-1080x1920.mp4`: 30 s vertical promo (Reels, Shorts, TikTok)
- `promo/final/pulse-promo-1920x1080.mp4`: 30 s landscape promo (YouTube, X)
- `website/assets/shots/*.png`: clean screenshots with made-up content (transparent backgrounds; put them on black)
- `.github/media/pulse-demo.gif`: 9 s loop

**Never use** `website/assets/silk.mp4`, `ribbon.mp4` or `doorway.mp4` (third-party footage), real songs or lyrics, or anything from your own desktop. Keep the made-up demo content ("Paper Lanterns" by "The Quiet Hours", `aurora-web`, `Navbar.tsx`).

**How to use a hook:** put the hook text on screen for the first 1.5 s, big, over the first frame of the clip. Then let the clip play. Keep captions honest: no "you need this", no fake numbers.

**Hashtag sets** (mix 5 to 8; don't paste the same set every time)
- Core: `#ClaudeCode #AI #coding #developer #opensource`
- Dev: `#programming #devtools #webdev #javascript #electron`
- Desk: `#desksetup #productivity #windows11 #macos #setup`

Every caption ends with: **"Free and open source. Not affiliated with Anthropic. Link in bio."** (On YouTube Shorts, put pulse-bot.dev in the description instead of "link in bio".)

## 5 follow-up shorts (one feature, 10–15 s each)

Record them from the real app with made-up content only. Two ways: add a scene to the film script (`src/main/film.js`, run with `npm run film -- --promo`; it plays scripted, made-up sessions in an empty profile and already has the gold theme), or screen-record a fresh demo profile you've filled with fictional data. Never record your real desktop.

1. **"Reply to Claude without the terminal" (12 s).** Claude finishes with a question ("Want me to add tests too?"). The pill shows "Asked you something". Hover, type "yes, for the navbar", Enter. The eyes switch to scanning. End card.
2. **"The moods" (10 s).** Four quick cuts of the pill: working (scanning eyes), asking (hop), done (smile), failed (droop), each labelled. Good loop for TikTok.
3. **"Phone to PC in 5 seconds" (14 s).** Open Tray → show the QR code → scan with a phone (show only the phone screen, made-up file "moodboard.png") → the file lands on the shelf → drag it into an app. Caption: local network only, link expires after an hour.
4. **"Reminders in plain words" (10 s).** Type "Stand-up" and "tomorrow 9:30am" in Plan; the reminder appears with its time; cut to the notification firing. Caption: no calendar app needed.
5. **"Make it yours" (10 s).** Settings → colour swatches → the island and eyes change colour with each pick, ending on a custom gold `#D28A0F` on black. Caption: pick any two colours, it keeps text readable.
